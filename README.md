## Notes

- The layout has dedicated breakpoints at 980px, 720px, 430px and 350px.
- Featured projects stack image-first on mobile so media can never cover the copy.
- The capabilities area becomes a swipeable card deck on smaller screens to reduce vertical text fatigue.
- Band Factory uses an image from the supplied Band Factory repository.
- `resume.html` contains an explicit portrait placeholder. Replace the `.portrait` block with your own `<img>` when ready.
- Footer socials are Snapchat `jvo_james`, Instagram `jvo.web` and TikTok `jvo.web`.
